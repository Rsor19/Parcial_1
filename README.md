Aplicación de escritorio JavaFX para gestionar un gimnasio con clientes, planes, entrenadores, servicios adicionales, inscripciones, consultas telefónicas e ingresos. El proyecto usa Maven y el patrón MVC.

## Requisitos

- JDK 21 o compatible.
- Apache Maven 3.9 o compatible.

Los datos se mantienen en memoria mientras la aplicación está abierta. Al cerrarla, los datos ingresados se pierden.
